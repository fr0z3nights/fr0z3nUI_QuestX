# fr0z3nUI QuestX

Auto-abandons quests based on your configured lists (account-wide and/or character).

## Install
1. Copy the folder `fr0z3nUI_QuestX` into:
	- `World of Warcraft/_retail_/Interface/AddOns/`
2. Launch WoW and enable the addon.

## Slash Commands
- `/fqx` — open the UI and focus the edit box

## SavedVariables
- Account: `fr0z3nUI_QuestX_Acc`, `fr0z3nUI_QuestX_Settings`
- Character: `fr0z3nUI_QuestX_Char`, `fr0z3nUI_QuestX_CharSettings`

## Notes
- Runs automatically on common quest-log related events; will defer actions when not safe to abandon.
